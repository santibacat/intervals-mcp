# Personal training context template

> Copy this file to `PERSONAL.md` and fill it with the active athlete's durable context. `PERSONAL.md` is ignored by Git.

> Do not store API keys, passwords, access tokens, payment data, or unrelated sensitive information. Store health information only when the athlete explicitly asks for it to be remembered.

## Profile

- **athlete_identity:** Not specified; confirm before merging information about different people.

## Goals and events

- **goals:** Add explicit goals, races, and target dates here.

## Availability

- **training_availability:** Add preferred training days, weekly hours, and recurring constraints here.

## Training preferences

- **training_preferences:** Add preferred sports, session types, and scheduling preferences here.

## Performance markers

- **performance_markers:** Add dated personal bests, thresholds, and zones here.

## Equipment and integrations

- **integrations:** Add connected platforms and equipment here.

## Health and constraints

- **current_health_status:** Unknown; ask before prescribing a demanding progression.
- **health_constraints:** Add only information the athlete explicitly asks the MCP to remember.

## Coaching notes

- **notes:** Add durable coaching context here; keep daily observations in Intervals.icu rather than this file.
